# Умный список покупок 🛒

Одностраничное PWA-приложение для списков покупок с привязкой к магазинам.
Все данные хранятся только в `localStorage` браузера — сервер не нужен.

## Стек

- React 18 + Vite
- Tailwind CSS
- React Router (`HashRouter`, чтобы приложение работало и офлайн, и при открытии из файловой системы)
- `@dnd-kit` — перетаскивание магазинов
- `framer-motion` — анимации (появление/исчезновение товаров, модальные окна)
- `vite-plugin-pwa` — манифест и service worker для установки на телефон

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`) на телефоне и компьютере.

## Сборка для продакшена / установки как PWA

```bash
npm run build
npm run preview
```

`npm run build` также генерирует `manifest.webmanifest` и service worker,
поэтому собранную версию (`dist/`) можно установить на телефон как
самостоятельное приложение и открывать офлайн.

## Структура проекта

```
src/
  context/ShoppingContext.jsx   — единый источник состояния + синхронизация с localStorage
  utils/storage.js              — чтение/запись localStorage, тема оформления
  utils/id.js                   — генерация id
  components/
    ShopList.jsx                — главный экран со списком магазинов (drag-and-drop)
    ShopCard.jsx                — карточка магазина
    ShopDetail.jsx               — экран товаров конкретного магазина
    AllItems.jsx                 — общий список товаров из всех магазинов
    ItemList.jsx                 — список товаров с чекбоксами и разделом «Купленные»
    AddItemForm.jsx               — форма добавления товара (нижний лист)
    Modal.jsx                    — переиспользуемое модальное окно
    ThemeToggle.jsx               — переключатель светлой/тёмной темы
    Icon.jsx                      — набор простых SVG-иконок
```

## Данные

Ключ в `localStorage`: **`shoppingAppData`**.

```json
{
  "shops": [
    {
      "id": "…",
      "name": "Название магазина",
      "items": [
        { "id": "…", "name": "Молоко", "quantity": "1 л", "purchased": false }
      ]
    }
  ],
  "shopOrder": ["id1", "id2"]
}
```

Тема оформления хранится отдельно, в ключе `shoppingAppTheme` (`"light"` или `"dark"`).

При первом запуске (если в `localStorage` ничего нет) создаётся демо-магазин
«Пример: Супермаркет» с парой товаров — чтобы интерфейс не выглядел пустым/сломанным.
